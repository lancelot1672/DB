# 02. Mode 2 — 직접 GRANT + CREATE SYNONYM

**상태: ✅ 구현 완료**

구현 위치: `01.GRANT_PRIV.sh:181-331` (`run_grant_mode()`)

## 요구사항

`DBM_PRIV_INF` 트리거를 거치지 않고 `GRANT` 문을 직접 실행하고, 접속 계정에 시노님을 만든다.

1. `OWNUSR`(테이블 소유 스키마) 입력
2. `CONUSR`(접속 계정) 입력 → 그 계정에 부여된 `RL%` 롤 목록 조회 → 1개 선택
3. PRIVILEGE 다중 선택 (기본 전체)
4. `OWNUSR` 의 전체 테이블에 대해 `GRANT` + `CREATE SYNONYM` SQL 생성 → 확인 후 실행

## 알려진 제약 / 개선 여지

의도된 동작이며 현재 요구사항 범위에서는 수정 대상이 아니다. 기록만 남긴다.

1. **롤 조회 조건이 `LIKE 'RL%'`** (`01:213`) — `RLOG_` 같은 롤도 걸린다.
   [03](03.MODE3_ROLE_BASED_GRANT.md) 은 `LIKE 'RL\_%' ESCAPE '\'` 를 쓰기로 했으므로,
   Mode 2 도 같이 맞추면 일관된다. **동작 변경이므로 별도 합의 후 수정할 것.**
2. **PRIVILEGE 선택 코드가 함수 밖 인라인** — [04](04.COMMON_PRIV_SELECT.md) 에서
   `_choose_privs()` 로 추출하며 이 블록은 함수 호출로 대체된다.
3. **GRANT SQL 은 권한별 파일 분리 없이 한 파일** — INSERT 방식과 다른 규칙이지만
   `GRANT SELECT, INSERT, ... ON t TO r;` 한 문장으로 처리되므로 분리할 이유가 없다. 유지.
