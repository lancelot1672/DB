# 01. Mode 1 — DBM_USR_INF 기준 DBM_PRIV_INF INSERT

**상태: ✅ 구현 완료** (단, [04](04.COMMON_PRIV_SELECT.md) 의 권한 선택 미적용)

구현 위치: `01.GRANT_PRIV.sh:359-563`

## 요구사항

1. `DBADM.DBM_USR_INF` 에서 `BSN`, `OWNUSR`, `CONUSR` 을 조회해 대상 선택
2. `OWNUSR` 기준으로 `DBA_TABLES` 를 훑어 `DBADM.DBM_PRIV_INF` 에 INSERT
3. 실제 GRANT 는 `DBM_PRIV_INF` 의 **내부 TRIGGER** 가 수행 (스크립트 범위 밖)

- `GRANTEE` = `RL_{BSN}_ALL`
- `PRIVILEGE` 별로 SQL 파일 분리, 각 파일 마지막 줄은 `COMMIT;`

```SQL
INSERT INTO DBADM.DBM_PRIV_INF (PRIVILEGE, OWNER, OBJECT_NAME, GRANTEE, CREATED)
VALUES ('SELECT', 'DBOWN', 'TABLE_NAME', 'RL_CORE_ALL', SYSDATE);
```

| 단계 | 위치 | 상태 |
|---|---|---|
| Pass 1 — `DBM_USR_INF` 조회, BSN 선택 (`ALL` 포함) | `01:367-442` | ✅ |
| Pass 2 — BSN × PRIVILEGE 별 INSERT SQL 생성 | `01:450-517` | ✅ |
| Pass 3 — 미리보기(파일별 TOP 3) + `y/N` | `01:522-539` | ✅ |
| Pass 4 — `sqlplus` 로 파일 순차 실행 | `01:544-563` | ✅ |
| 생성 파일 `./sql/1_{BSN}_{S\|I\|U\|D}_{YMD}_{HMS}.sql` | `01:903` | ✅ |
| 마지막 줄 `COMMIT;` | `01:507` | ✅ |
| 대상 0건 시 `_fail` 후 종료 | `01:394-399`, `01:513-517` | ✅ |

동작 상 참고:
- 생성 파일에는 `EXIT` 가 없어 `sqlplus ... @${f} < /dev/null` 로 EOF 를 먹여 종료시킨다 (`01:552`).
- BSN 하나에 OWNUSR 이 여러 개여도 같은 파일에 append 되도록 `spool ... append` 를 쓴다 (`01:482`).

## 남은 작업

### PRIVILEGE 선택 적용 (⬜)

현재 `01.GRANT_PRIV.sh:34` 의

```bash
PRIVS="SELECT INSERT UPDATE DELETE"
```

가 하드코딩되어 **항상 4개 파일을 생성한다**. 이를 [04](04.COMMON_PRIV_SELECT.md) 의
`_choose_privs()` 결과(`SEL_PRIVS`)로 교체하여 선택한 권한의 파일만 생성한다.

- 호출 위치: Pass 1(대상 선택) 직후, Pass 2(SQL 생성) 직전
- `01:474` 의 `for PRIV in ${PRIVS}` → `for PRIV in ${SEL_PRIVS}`
- 상수 `PRIVS` 는 폴백 기본값 용도로만 남기거나 제거

### 적용 방식 선택 (해당 없음)

Mode 1 은 정의상 INSERT 방식이므로 [05](05.COMMON_APPLY_METHOD.md) 의 방식 선택을
**묻지 않는다.** 방식 선택은 최상위 운영 메뉴에서 Mode 1 / Mode 2 를 고르는 것으로 이미 갈린다.
