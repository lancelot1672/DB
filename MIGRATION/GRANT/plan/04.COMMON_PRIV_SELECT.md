## 요구사항

모든 모드의 **마지막 입력 단계**에서 부여할 권한을 고른다.

- 항목: `SELECT` / `INSERT` / `UPDATE` / `DELETE`
- 조작: ↑/↓ 이동, **SPACE 토글**, Enter 확정
- **DEFAULT 는 4개 전부 체크된 상태** — 그냥 Enter 치면 전부 선택
- 중복(다중) 선택 가능
- 하나도 선택하지 않고 Enter → `_fail "At least one privilege must be selected"` 후 중단

## 구현 내용

### 1. `_choose_privs()` 함수 (✅)

결과를 전역 두 변수로 내보낸다.

| 변수 | 형태 | 용도 |
|---|---|---|
| `SEL_PRIVS` | 공백 구분 — `"SELECT UPDATE"` | 반복문 / 파일명 생성 (INSERT 방식) |
| `GRANT_PRIV_CSV` | 콤마 구분 — `"SELECT, UPDATE"` | `GRANT` 문 생성 (GRANT 방식) |

```bash
# ------------------------------------------------------------
# _choose_privs : SELECT/INSERT/UPDATE/DELETE multi-select.
#   result : SEL_PRIVS (space separated), GRANT_PRIV_CSV (comma separated)
#   return : 0 on success, 1 if nothing selected
# ------------------------------------------------------------
_choose_privs() {
    local PMENU=("SELECT" "INSERT" "UPDATE" "DELETE")
    _out "  Select privileges (Up/Down move, SPACE toggle, Enter confirm):\n"
    if _multi_select_menu "${PMENU[@]}" ; then
        SEL_PRIVS="${MULTI_RESULT}"
    else
        printf "  Enter privileges (space/comma separated, blank=ALL): "
        read -r SEL_PRIVS
        SEL_PRIVS=$(echo "${SEL_PRIVS}" | tr ',' ' ' | tr '[:lower:]' '[:upper:]')
        [[ -z "$(echo ${SEL_PRIVS} | tr -d '[:space:]')" ]] && SEL_PRIVS="SELECT INSERT UPDATE DELETE"
    fi
    if [[ -z "$(echo ${SEL_PRIVS} | tr -d '[:space:]')" ]] ; then
        _fail "At least one privilege must be selected"
        return 1
    fi
    GRANT_PRIV_CSV=$(echo ${SEL_PRIVS} | xargs | sed 's/ /, /g')
    PRIV_CODE=$(_priv_code "${SEL_PRIVS}")
    _log "Selected privileges: ${GRANT_PRIV_CSV}  (code=${PRIV_CODE})"
    return 0
}
```

- 배치: `_multi_select_menu` 정의 직후 (`01:226`)
- Mode 2 의 기존 인라인 블록은 `_choose_privs || return 1` 한 줄로 대체 (`01:456`)

### 2. Mode 1 에 적용 (✅)

- 호출: Pass 1(대상 선택) 종료 후, Pass 2 시작 전 — `01:837`
  ```bash
  _choose_privs || { _cleanup; exit 1; }
  ```
  (모드 함수가 아니라 최상위 스크립트라 `return` 이 아니라 `_cleanup` + `exit`)
- `for PRIV in ${PRIVS}` → `for PRIV in ${SEL_PRIVS}` (`01:869`)
- `PRIVS` → `PRIVS_DEFAULT` 로 개명, 폴백 기본값 용도로만 유지 (`01:45`)

### 3. Mode 3 에 적용 (✅)
